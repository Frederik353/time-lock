time lock: the math

A time lock seals a short secret so that getting it back always costs a fixed stretch of waiting. It is not a password you can forget; it is a delay you have to sit through. It is built to outlast a bored impulse, not a determined attacker.

Locking picks two random ~1024-bit primes (Miller-Rabin tested) and multiplies them into a ~2048-bit modulus, along with a random base g:

N = p · q   (p, q ≈ 1024-bit primes)

The answer is a single number, reached by squaring g a huge number of times, t of them:

key = g^(2ᵗ) mod N

Locking knows the factors, so it knows φ(N) = (p−1)(q−1) and takes Euler's shortcut: shrink the exponent first, then one modular exponentiation lands on the key instantly.

e = 2ᵗ mod φ(N)
key = gᵉ mod N

Then it throws p, q and φ(N) away. Unlocking is left with only N, g and t. With no factors there is no shortcut. The only known route to the key is to actually walk the t squarings, one after another:

x₀ = g
xᵢ = xᵢ₋₁² mod N
key = xₜ

Each square needs the one before it, so the work is inherently sequential: more cores, a GPU, splitting it up, none of it helps. That unavoidable chain is the delay. (The Rivest-Shamir-Wagner time-lock puzzle, 1996.)

How big is t? When you lock, it measures how many squarings per second this machine manages and sets t = rate × seconds. The wait is calibrated to the device you lock on, and it is honest about hardware: unlock on something much faster and it finishes sooner.

The secret itself is encrypted with AES-GCM under key = SHA-256(xₜ). The reset/pause choice is mixed into GCM's authenticated data, so flipping that flag in the token makes the final decryption fail. You change the behaviour by rewriting this page, not by editing the token.

reset wipes all progress if you leave the tab, so an impulse costs you the whole wait again; pause only stops the clock, for long locks where you still need the phone. Either way the screen is kept awake while it grinds.

Friction, not a vault: the token isn't secret, and faster hardware or code could solve it quicker. Everything runs in your browser; nothing is ever sent anywhere.
